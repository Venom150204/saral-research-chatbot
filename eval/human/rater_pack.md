**Script:**

When we train extremely deep neural networks, we encounter a fundamental optimization obstacle where accuracy rapidly saturates and then degrades, and this degradation is caused by optimization difficulty rather than overfitting. In standard feedforward networks, stacking layers forces nonlinear solvers to approximate complex underlying mappings from scratch, which becomes increasingly intractable as depth grows. To bypass this limitation, the authors reformulate stacked layers to learn a residual function F of x equals H of x minus x, where x represents the input to the layer block. An identity shortcut connection bypasses the nonlinear transformations by directly adding the input x to the stacked layer output F of x, yielding the desired underlying mapping H of x. Crucially, these identity shortcut connections introduce zero extra parameters and add no computational complexity to the network architecture. From an optimization perspective, if an identity mapping were optimal, it is much easier for a solver to push the residual weights toward zero than to fit an identity mapping using unmanaged stacked nonlinear layers. Combined with batch normalization ensuring healthy signal propagation and preventing vanishing gradients, this residual formulation successfully enables the stable training of extremely deep networks.

To overcome this fundamental limitation, the Transformer architecture entirely replaces recurrence and convolutions with attention mechanisms, allowing much greater parallelization for sequence models and significantly faster training.
